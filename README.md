Memory Card Game — Resume-style README

## Summary

This is a lightweight memory card game built with HTML, CSS, and JavaScript. The game challenges players to match pairs of cards by flipping them over and remembering their positions. It's designed as a small, accessible browser game suitable for learning, demos, or embedding in web pages.

## Key Highlights

- **Project:** Memory Card Game — simple browser-based matching game.
- **Tech Stack:** HTML, CSS, JavaScript (no build steps or external dependencies).
- **Purpose:** Demo, learning exercise, small game for portfolio or teaching.

## How to Get It

- **Clone repository:** `git clone https://github.com/Mehdi-133/memory-card-game.git`

## How to Run

- **Open locally:** Double-click `index.html` or open it in your browser.
- **Serve for development (optional):** Run a simple static server if you prefer, e.g.:

```powershell
# using Python 3
python -m http.server 8000
# then open http://localhost:8000/
```

## Project Structure

- **`index.html`**: Game entry page and layout.
- **`style.css`**: Visual styles and layout rules.
- **`script.js`**: Game logic, state management, and event handlers.
- **`assets/`**: Static assets used by the game, e.g. images.
  - **`assets/images/`**: Card faces and other images.
- **`README.md`**: This file (resume-style overview).

## How the Game Works (brief)

- The board shows a grid of face-down cards.
- Players click to flip two cards at a time.
- Matching pairs remain face-up; non-matching pairs flip back.
- Game ends when all pairs are matched. A score/timer can be added easily.
